# E-Commerce Purchase Conversion Analytics

## Project Overview
This project analyzes online shopping sessions to identify behavioral patterns associated with completed purchases and convert those findings into actionable business insights.

The project follows the internship's business-intelligence flow:

**Data → Information → Insight → Decision → Action**

## Dataset
**UCI Online Shoppers Purchasing Intention Dataset**

- 12,330 sessions
- 18 attributes
- Business/e-commerce domain
- Target: `Revenue`
- No missing values
- Source: UCI Machine Learning Repository
- DOI: 10.24432/C5F88Q
- Dataset page: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset

The dataset is not one of the masterclass datasets identified for this internship (the masterclass examples used Superstore, Telco churn and bank marketing data).

## Project Questions
1. What is the overall purchase conversion rate?
2. How does conversion differ between new and returning visitors?
3. Which months show stronger purchase conversion?
4. How does weekend behavior compare with weekday behavior?
5. How is conversion associated with page-value signals?
6. Which traffic types show stronger conversion?
7. How does exit-rate behavior relate to conversion?

## Files
- `analysis.py` — complete analysis and chart generation
- `app.py` — interactive Streamlit dashboard
- `requirements.txt` — Python dependencies
- `project_report.docx` — project report
- `project_report.pdf` — PDF version of the report
- `README.md` — project documentation

## How to Run
```bash
pip install -r requirements.txt
python analysis.py
streamlit run app.py
```

The dataset is fetched programmatically from UCI through `ucimlrepo`, so the large raw dataset does not need to be stored inside the repository.

## Dashboard
The Streamlit dashboard contains:
- KPI cards
- Visitor-type conversion
- Monthly conversion
- Weekday/weekend conversion
- Page-value conversion
- Business interpretation and recommended actions

## Business Outcome
The project is designed to help an e-commerce team understand which session characteristics are associated with purchase completion and where conversion-focused actions can be applied.

## Important Note
The numerical results shown in the final report should be regenerated by running `analysis.py` with the current UCI dataset. This keeps the analysis reproducible and prevents manually entered results from becoming stale.
